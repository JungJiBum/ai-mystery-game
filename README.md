# AI Story

네이버 블로그 미스터리 소설과 연결되는 웹 기반 인터랙티브 추리 게임입니다. 현재 **EP01-01 「발신인 없는 택배」의 플레이 가능한 프로토타입**을 구현했습니다. 에피소드 01 전체나 이후 회차는 구현 범위에 포함하지 않습니다.

**현재 상태: 로컬 구현·검증 완료, 아직 미배포.** GitHub 원격 저장소 생성·연결·푸시는 진행하지 않았습니다.

## 구현된 플레이

게임 시작 → 현관의 택배 → 실내에서 상자 개봉 → 물건 조사·증거 수집 → 단서 연결 → 12년 전 연구소 화재 기사 → EP01-01 완료 화면.

- 현관·실내·택배 내부를 구분하는 장면과 인벤토리
- 가족사진 앞·뒷면 뒤집기, 쪽지 펼치기·다시 접기
- 검은색 USB 외관의 100~300% 확대·축소·스크롤 (컴퓨터 연결 기능 없음)
- 사진 앞면·뒷면, 쪽지 안쪽, USB의 증거 4개 수집과 썸네일 재조사
- 증거 두 개 연결과 오답 재시도, 기사 해금, 별도 완료 화면
- localStorage 자동 저장·이어하기·완료 복원·확인 후 초기화
- 기존 v1 저장 데이터 이전, 저장이 차단되어도 현재 페이지에서 플레이
- 모바일 반응형, 키보드 조작, 조사 창 초점 복귀, 동작 줄이기 설정 지원

사진 뒷면과 쪽지의 원문은 이미지·HTML 전사·접근성 설명·추리 단서에서 일치하도록 관리합니다. 택배 발신인·화재 원인·흑막·USB 내용 등 미확정 설정은 확정하지 않았습니다.

## 이미지와 기술 구성

제공된 WebP 이미지 **9개**를 `web/assets/images/ep01-01/`에 적용했습니다. 표지, 현관, 실내, 택배 내부, 사진 앞·뒷면, 접힌·펼친 쪽지, USB이며 모두 1024×680입니다. 외부 이미지 URL을 사용하지 않습니다. USB 300% 확대는 원본의 보간 확대입니다.

HTML·CSS·Vanilla JavaScript 기반의 정적 웹입니다. 백엔드·DB·유료 API·빌드 단계 없이 실행합니다. 장면·대사·원문·증거·추리 데이터와 이미지 경로를 게임 로직에서 분리했습니다.

## 로컬 실행

저장소 루트에서 다음 명령을 실행하고 브라우저로 http://localhost:8080 을 엽니다.

```sh
python3 -m http.server 8080 --directory web
```

서버 종료는 Ctrl+C입니다. 저장 데이터는 브라우저와 접속 주소별로 유지됩니다.

## 테스트 현황

- Node.js 자동 회귀 테스트 **13개 통과**: 원문, 추리 조합·잠금, 저장 검증·이전·완료 복원, 활성 이미지 파일 확인
- 실제 이미지 연결 후 시작부터 기사·완료까지 전체 플레이 확인
- 사진·쪽지·완료 상태 새로고침 복원, 초기화 취소·확정, 오답 재시도 확인
- 320px·390px·1280px 프레임의 표시·잘림·가로 넘침 점검
- 정상 연결 상태의 브라우저 콘솔 경고·오류 없음

Node.js가 설치된 환경에서 테스트를 다시 실행할 수 있습니다. 별도 npm 설치는 필요 없습니다.

```sh
node --test web/tests/state.test.mjs
```

브라우저 검증은 로컬 환경에서 수행했습니다. 실제 GitHub Pages 배포 환경과 다른 브라우저·실기기는 아직 별도 검증하지 않았습니다. 자세한 기록은 [web/TESTING.md](web/TESTING.md)에 있습니다.

## 배포 상태

**아직 배포하지 않았으며 공개 게임 URL은 없습니다.** GitHub Pages용 워크플로는 준비되어 있지만 `workflow_dispatch` 수동 실행만 허용합니다. 커밋이나 푸시로 배포가 자동 실행되지 않습니다.

향후 GitHub 업로드와 배포는 별도로 진행합니다. 수동 배포 시에는 저장소의 Pages 소스를 GitHub Actions로 설정한 뒤 워크플로를 실행하며, 배포 대상은 `web/`입니다.

자세한 플레이·저장 설명은 [web/README.md](web/README.md), 이미지 연결 정보는 [이미지 안내](web/assets/images/ep01-01/README.md)를 참고하세요.
