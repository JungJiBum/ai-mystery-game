# EP01-02 이미지 자산

현재 이미지는 제공되지 않았습니다. 임의 이미지 생성 및 기존 이미지 편집을 수행하지 않았습니다. 기존 가족사진은 EP01-01의 `photoFront` 자산을 참조합니다.

| 키 | 예약 경로 | 내용 |
| --- | --- | --- |
| fire | `web/assets/images/ep01-02/fire-scene.webp` | 기사 속 밤의 연구소 화재 현장 사진 |
| search | `web/assets/images/ep01-02/search-results.webp` | 연구소와 기록실 검색 결과 |
| press | `web/assets/images/ep01-02/press-release.webp` | 사고 당시 공식 보도자료 |

각 파일을 이 디렉터리에 넣고 `web/js/episodes/ep01-02/assets.js`의 해당 `ready`를 `true`로 변경하면 연결됩니다. PNG/JPG 파일을 사용하면 `file`의 확장자도 변경하세요. 표시 방식은 `object-fit: contain`이며 인용문은 이미지와 별개로 HTML에 유지됩니다. 이미지 로드 실패 시 대체 UI로 진행할 수 있습니다.

화재 사진은 원고의 ‘밤의 연구소, 깨진 창문, 건물 위 검은 연기’ 범위로 준비합니다. 특정 화재 원인이나 범인을 묘사하지 않습니다. 검색 화면에는 실제 연구소 이름이나 실제 삭제 URL을 새로 만들지 않습니다.

이미지에 글자를 넣는 경우 아래 원고 인용과 정확히 일치해야 합니다.

- 검색 미리보기: `화재 발생 당시 내부 기록 보관 구역의 출입 이력은…`
- 보도자료: `사고 관련 내부 기록은 관계 기관에 제출하였으며, 원본은 보존 규정에 따라 관리 중입니다.`

기존 가족사진에서는 원고의 안내판 글자를 식별할 수 없습니다. 원본을 수정하지 않고, 게임의 ‘가족사진 안내판 확대 판독’에서 원고 문구 `…기록실`을 HTML로 제시합니다. 실제 이미지 기반 확대와 일치시키려면 향후 별도 승인된 이미지가 필요합니다.
