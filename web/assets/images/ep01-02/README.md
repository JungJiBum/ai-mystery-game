# EP01-02 이미지 표시 정책

제공 ZIP의 PNG 3개는 원본 바이트 그대로 보관합니다. 이미지 생성·편집·재인코딩은 하지 않았습니다.

| ID | 파일 | 원본 크기 | 화면 표시 |
| --- | --- | --- | --- |
| fire | `fire_scene.png` | 558×754 | 기사·사진 비교에서 크롭 |
| search | `archive_search.png` | 489×754 | 표시하지 않음 |
| press | `press_release.png` | 511×754 | 표시하지 않음 |

`web/js/episodes/ep01-02/assets.js`에서 fire만 `ready: true`입니다. CSS 표시 영역은 원본 좌표 x=0, y=220, 너비=360, 높이=270으로 4:3입니다. 기관명 표지가 있는 오른쪽 영역을 제외하며 검은 오버레이·흐림 처리는 없습니다. 원본 파일을 교체하면 크기와 크롭 영역을 다시 검토해야 합니다. 파일 로드 실패 시 대체 표시와 기존 HTML 조사를 유지합니다.

검색·보도자료 PNG에는 원고와 다른 기관명·날짜·문구가 있어 렌더링 자체를 제거했습니다. `ready`를 바꾸어도 화면에 다시 나타나지 않습니다. 검색 폼·결과·삭제된 페이지와 공식 보도자료는 HTML로 제공합니다.

가족사진과 화재 사진만으로 같은 건물임을 입증할 수 없습니다. 기존 원고 기반 안내판 판독 `…기록실`을 유지하며 이미지를 정답 판정에 사용하지 않습니다. 플레이 화면에는 개발·검증용 안내 문구를 표시하지 않습니다.

공식 인용문과 추리 데이터는 `web/js/episodes/ep01-02/story.js`를 기준으로 유지합니다. 보도자료의 원문은 다음과 같습니다.
