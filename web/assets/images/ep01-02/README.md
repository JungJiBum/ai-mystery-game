# EP01-02 이미지 적용과 원고 우선 정책

`EP01-02_image_assets.zip`의 PNG 3개를 원본 바이트 그대로 연결했습니다. 재인코딩·이미지 생성·기존 이미지 수정은 하지 않았습니다. ZIP의 전체 접촉 시트와 참고 README는 게임 자산에 포함하지 않았습니다.

| 키 | 파일 | 원본 크기 | 게임에서의 역할 |
| --- | --- | --- | --- |
| fire | `fire_scene.png` | 558×754 | 기사·사진 비교 장면의 화재 후 외관 참고 |
| search | `archive_search.png` | 489×754 | 검색 HTML 아래 화면 구성 참고 |
| press | `press_release.png` | 511×754 | 공식 HTML 본문·진행 버튼 아래 문서 형식 참고 |

모두 `web/js/episodes/ep01-02/assets.js`에서 `ready: true`로 활성화했습니다. `width`·`height`를 기준으로 원본 비율을 유지하며 `object-fit: contain`으로 표시합니다. 파일을 교체하면 경로·크기·가림 영역과 설정 일치 여부를 다시 검토해야 합니다.

## 설정 불일치 처리

이미지에는 원고에 없는 기관명·구체적인 날짜·시각·문구가 있습니다. 특히 보도자료 강조 문장은 원고의 공식 보존 문구와 다릅니다. 이를 게임 설정·정답·단서 데이터로 가져오지 않았습니다.

- 화재 이미지의 기관명 표지는 불투명한 CSS 가림 영역으로 덮습니다. 가림은 원본 파일 편집이 아닌 게임 화면의 표시 처리입니다.
- 검색·보도자료 이미지는 전체에 CSS 흐림과 덮개를 적용해 잘못된 글자가 읽히지 않도록 합니다. 원본을 확대하거나 가림을 해제하는 기능은 제공하지 않습니다.
- 검색·보도자료 이미지는 장식용(`alt=""`, `aria-hidden="true"`)으로 처리하고, 접근성 설명과 공식 단서는 원고 기준 HTML로 제공합니다.
- 이미지마다 참고용 표시와 ‘기관명·날짜·문구는 게임의 설정이나 정답이 아님’을 안내합니다.
- 검색 입력·검색 결과·삭제 흔적·보존 문구·단서 연결은 기존 HTML과 상태 로직을 유지합니다. 보도자료 참고 이미지는 공식 본문 밖에 있습니다.

원본 PNG를 직접 열면 검증되지 않은 글자가 그대로 존재합니다. 저장소에 보존한 원본과 게임 화면의 가림 처리는 구분해야 합니다. 해당 원본을 공식 설정 자료로 인용하면 안 됩니다.

## 화재 이미지와 사진 비교의 제한

제공된 화재 이미지는 사고 후 외관으로 보이며, 원고의 ‘밤의 연구소, 깨진 창문, 검은 연기’ 장면을 그대로 재현한 사진은 아닙니다. 기존 가족사진에서는 건물 전체와 안내판 글자가 식별되지 않으므로 **동일 건물이라는 시각적 검증은 불가능**합니다.

따라서 이미지를 동일 건물의 증거라고 표시하지 않고 외관 참고로 명시합니다. 원고의 사진 비교 전개와 ‘가족사진 안내판 확대 판독’ 기능은 그대로 유지하며, 단서는 기존과 같이 HTML의 `…기록실` 판독으로 제공합니다. 이 비교를 실제 이미지 증거로 구현하려면 원고·가족사진과 일치하는 추가 자산이 필요합니다.

## 변경하지 않은 공식 인용

- 안내판: `…기록실`
- 검색 미리보기: `화재 발생 당시 내부 기록 보관 구역의 출입 이력은…`
- 공식 보도자료: `사고 관련 내부 기록은 관계 기관에 제출하였으며, 원본은 보존 규정에 따라 관리 중입니다.`

이 문구는 `web/js/episodes/ep01-02/story.js`에서 관리하고 HTML·추리에서 공유합니다. 이미지의 기관명·날짜·문구를 인용문에 덧붙이지 않습니다.

파일 누락·로드 실패 시 대체 표시로 돌아가고 HTML 조사·원고 판독은 유지됩니다. `ready: false`로 설정하면 이미지를 요청하지 않고 기존 대체 UI를 사용할 수 있습니다.
