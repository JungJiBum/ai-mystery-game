# EP01-01 연결 이미지

제공된 `ai_story_ep01_01_assets.zip`에서 아래 WebP 9개를 가져왔습니다. **모두 1024×680, RGB**이며 원본 파일은 편집하지 않았습니다. `web/js/assets.js`의 해당 항목은 모두 `ready: true`입니다.

| assets.js 키 | 연결 파일 | 역할 |
| --- | --- | --- |
| cover | cover.webp | 연구소 화재 표지 |
| entrance | entrance.webp | 현관 문 앞 닫힌 택배 |
| room | room.webp | 실내 탁자 위 닫힌 택배 |
| parcelOpen | parcel-open.webp | 열린 상자와 세 물건 |
| photoFront | photo-front.webp | 가족사진 앞면 |
| photoBack | photo-back.webp | 원문이 적힌 가족사진 뒷면 |
| noteFolded | note-folded.webp | 접힌 쪽지 |
| noteOpen | note-open.webp | 원문이 적힌 펼친 쪽지 |
| usb | usb.webp | 검은색 USB 외관 |

## 표시 방식과 교체

표지·장면·사진·쪽지는 원본 비율 `128 / 85`로 표시합니다. `object-fit: contain`을 사용하므로 이미지의 문구와 테두리가 잘리지 않습니다. 썸네일도 원본 전체를 축소합니다. USB는 화면 안에 전체 이미지를 담은 뒤 100~300%로 확대하며, 확대 전 관찰 위치를 유지하고 영역을 스크롤할 수 있습니다.

이미지를 바꾸려면 같은 파일명으로 교체하거나 `assets.js`의 `file`을 수정하세요. 일부 파일을 아직 제공하지 않는 경우 해당 `ready`를 `false`로 설정하면 요청 없이 준비 중 표시로 돌아갑니다. `ready: true`인데 파일이 없거나 손상된 경우에는 로드 실패 대체 표시가 나타나며 플레이는 계속할 수 있습니다.

PNG/JPG로 교체할 때는 확장자를 정확히 바꾸고 대소문자를 일치시켜 주세요. 증거 이미지는 물건 전체를 담고 사진 앞·뒷면 비율을 같게 유지합니다. 비율을 변경할 때는 `web/css/style.css`의 관련 `aspect-ratio`도 확인하세요. 조사 버튼 위치는 제공된 택배 내부 구도에 맞췄으며, `.hotspot-photo`, `.hotspot-note`, `.hotspot-usb`에서 조정합니다.

## 원문 검증

사진 뒷면:

> 기록은 사라져도, 사실은 사라지지 않는다.

쪽지 안쪽:

```text
당신의 부모님에 관한 기록입니다.
믿지 않아도 좋습니다. 직접 확인하십시오.
```

이미지의 단어·쉼표·마침표를 원문과 육안 대조했습니다. 이미지 안의 시각적 줄바꿈은 사진 뒷면 2줄, 쪽지 4줄이며, HTML 쪽지 전사는 원작의 두 문장 묶음을 두 줄로 유지합니다. 화면 폭에 따라 HTML도 자연스럽게 줄바꿈됩니다. DOM 문자열은 원문과 정확히 같습니다.

프로그램 원문은 `web/js/story.js`의 `quotes`에서 관리하며, 대체 텍스트·조사 화면 전사·추리 선택지가 이를 공유합니다. 정상 이미지가 연결되면 이미지 위 보조 문구는 숨기고, 이미지 아래 원문과 접근성 설명은 유지합니다. 이미지 글자는 코드가 자동 교정하지 않으므로 향후 교체 시 다시 대조해야 합니다.

현재 원본 가로 해상도는 1024px입니다. USB의 300% 확대는 보간 확대이며 원본에 없는 세부 정보가 추가되는 것은 아닙니다. 추후 더 높은 해상도 파일로 교체해도 경로와 조작 방식은 유지할 수 있습니다.

기존 `../parcel.svg`는 이전 버전 참고 파일이며 게임에서 사용하지 않습니다. 외부 이미지 URL과 배포 작업은 사용하지 않았습니다.
