## 자산 연결·예외 상태 검증

저장소 밖의 임시 복사본과 별도 로컬 origin에서 진단용 PNG를 사용했습니다. 이 이미지는 최종 자산이 아니며 저장소에 추가하지 않았습니다. 임시 테스트 도구도 제품 코드에 포함하지 않았습니다.

- 실제 로컬 이미지 로드 및 인벤토리 썸네일 표시 확인
- 사진 뒷면 이미지 alt가 원문에서 생성됨을 확인
- USB 이미지 확대 시 실제 렌더링 크기 증가 확인
- 연결된 이미지의 파일이 없을 때 로드 실패 대체 표시·확대·수집 유지
- v1 방 안의 4개 증거 보존 및 이전 정답 해금 초기화 확인
- v1 엔딩은 기사 화면으로 복원됨을 확인
- 손상된 저장 JSON에서 게임 시작 화면으로 복구 확인
- localStorage 접근을 차단한 상태에서도 새 게임 → 전체 조사 → 기사 → 완료 플레이 확인

## 반응형·접근성

임시 테스트 프레임으로 폭을 고정하여 측정했습니다. 스크롤바가 차지하는 폭을 제외한 문서 너비와 스크롤 너비가 같아 가로 넘침이 없었습니다.

| 프레임 폭 | 문서 clientWidth / scrollWidth | 배치 |
| --- | --- | --- |
| 320px | 305 / 305px | 한 열, 사진 조사 창 폭 271px |
| 390px | 375 / 375px | 한 열 |
| 1280px | 1265 / 1265px | 조사 794.5px + 인벤토리 300px |

버튼과 체크박스는 네이티브 키보드 조작을 유지합니다. 이미지 위 조사 버튼과 하단 물건 카드가 동일한 기능을 제공합니다. 사진 숨겨진 면에는 `aria-hidden`, 쪽지에는 `aria-expanded`와 숨겨진 전사, 확대율과 수집 알림에는 라이브 안내를 사용합니다. CSS의 `prefers-reduced-motion`에서 애니메이션을 제거합니다.

## 최종 이미지 제공 후 확인할 항목

현재 완료한 것은 이미지 슬롯과 상호작용·진행 흐름입니다. 실제 작품 이미지의 품질·글자 가독성·구도는 자산 수령 후 검증해야 합니다.

1. 이미지의 사진 뒷면·쪽지 글자가 원문과 정확히 일치하는지 대조
2. 사진 앞·뒷면의 비율·방향이 일치하고 회전 시 자연스러운지 확인
3. 접힌 쪽지에는 안쪽 글이 노출되지 않는지 확인
4. USB가 300% 확대에서도 관찰 가능한지 확인
5. 택배 내부 조사 버튼 위치와 물건 구도, 모바일 가독성 확인
6. 최종 이미지가 연결된 상태로 전체 플레이·저장 복원 재확인

다른 브라우저·실기기 및 실제 GitHub Pages 배포 환경에서는 별도 검증하지 않았습니다.
